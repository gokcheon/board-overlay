[보드게임 오버레이] 배포용 설치마법사 만들기 — 곡천용 안내
============================================================

■ 딱 두 단계
1) Inno Setup 6 설치 (한 번만)
   - https://jrsoftware.org/isdl.php 에서 innosetup-6.x.exe 받아서 기본 옵션으로 설치.
   - 안 깔려 있으면 빌드.bat이 알아서 이 페이지를 열어줘요.
2) [빌드.bat] 더블클릭
   - exe 빌드(2~5분) → 리소스 복사 → 설치마법사 컴파일까지 자동.
   - 완성되면: 배포용\보드게임오버레이_설치.exe

■ 나눠줄 파일
- "배포용\보드게임오버레이_설치.exe" 이 파일 하나면 끝.
- 받는 사람은 Python 설치 필요 없음! (exe 안에 전부 들어 있어요)

■ 받는 사람이 하는 일
1) 설치exe 실행 → 다음 → 다음 → 설치 (바탕화면 바로가기 기본 체크)
   - 처음 실행 시 파란 SmartScreen 창이 뜰 수 있어요 (서명 없는 프로그램이라 정상).
     [추가 정보] → [실행] 누르면 돼요. 배포할 때 이 말을 같이 전해 주세요.
2) 바탕화면의 🎲 [보드게임 오버레이] 더블클릭 → 런처가 뜨고 서버 자동 시작
3) 런처에 뜨는 주소를 OBS 브라우저 소스(오버레이)와 조작 기기(조작앱)에 입력
   - 방화벽 허용은 설치할 때 자동 등록되어서 팝업이 안 떠요.
   - 원컴 방송이면 시작 메뉴의 [조작앱 (원컴용)]으로 조작 창을 열면 돼요.

■ 업데이트 배포
- 새 fix가 나오면 빌드.bat만 다시 돌려서 새 설치exe를 나눠주면 돼요.
- 덮어서 설치해도 사용자의 보드·설정·스티커는 안 지워져요
  (%LOCALAPPDATA%\board_overlay 에 따로 저장 — 삭제(언인스톨)해도 남아요).

■ 참고
- 백신이 드물게 PyInstaller exe를 오탐할 수 있어요. 그럴 땐 예외 등록 안내가 필요해요.
- 빌드는 윈도우에서만 돼요 (exe는 윈도우 전용이라서).
- 빌드 중 에러가 나면 까만 창 내용을 복사해서 Claude에게 그대로 보여주세요.

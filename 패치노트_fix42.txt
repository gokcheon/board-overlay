[보드게임 오버레이 1.0 fix42] 패치노트 — 칸 통이미지 + 예상 메모리 표시

■ 칸 꾸미기 방식 2택 (설정 → 테마 설정)
- [기본] 지금까지 방식 — 앱이 칸 바탕·테두리·이름 글자·색 구분 바를 그리고 스티커를 3자리에 얹어요.
- [칸 통이미지] 칸마다 넣은 그림 한 장이 칸 전체를 대신해요.
  · 칸 테두리·색 구분 바·칸 이름 글자를 앱이 안 그려요 (그림에 다 들어 있으니까요)
  · 칸 그림은 [칸 편집] 서랍의 [칸 그림]에서 고릅니다
  · 그림을 안 넣은 칸은 자동으로 [기본] 방식으로 그려져요 — 빈 구멍이 안 생겨요
  · 진행 중에도 바꿀 수 있어요 (표시 전용이라 게임 진행과 무관)

■ 장식이 칸 밖으로 튀어나갈 수 있어요
- 칸 그림 캔버스를 칸보다 사방 60픽셀 크게 잡으면, 여백에 그린 장식이 칸 밖으로 넘쳐요.
- 권장 규격 (칸 크기 → 캔버스 → 내보내기 2배)
  · 모서리 4칸        269 x 205  ->  389 x 325  ->  778 x 650
  · 위·아래 줄 14칸   179 x 205  ->  299 x 325  ->  598 x 650
  · 좌·우 줄 8칸      269 x 137  ->  389 x 257  ->  778 x 514
- 테두리와 둥근 모서리는 그림에 직접 넣으세요 (앱은 안 그려요).
- 말이 서 있는 칸 표시(핑크 링)는 앱이 그리니 그림에 넣지 마세요.
- ※ 화면 바깥쪽은 여유가 없어요 — 윗줄 위·아랫줄 아래 32픽셀, 좌·우 줄 바깥 16픽셀까지만
  보이고 그 밖은 잘려요. 보드 안쪽으로는 제한 없어요.

■ 칸끼리 겹치는 순서
- 화면 아래쪽 칸이 위, 같은 줄이면 오른쪽 칸이 위로 그려져요.
- 말은 항상 칸보다 위, 전광판·상태바·타이머는 항상 칸 그림보다 위예요.

■ 현재 칸(말이 서 있는 칸) 강조
- 통이미지가 테두리까지 덮어 버려서, 강조를 그림 바깥에 또렷한 핑크 링으로 그려요.
- 기본 방식일 때의 강조는 지금까지와 똑같아요.

■ 예상 메모리 표시 (신규)
- 설정 → 이미지 관리, 설정 → 테마 설정 두 곳에 표시돼요.
  "지금 오버레이가 쓰는 그림 26장 · 예상 메모리 41.0MB (1080p 화면 5.2장 분량)"
- 그림마다 가로x세로와 MB도 같이 보여요.
- ★이 MB는 파일 크기가 아니에요. OBS 브라우저 소스는 그림을 화면에 보이는 크기가 아니라
  원본 가로세로 픽셀만큼 메모리에 펼쳐서 들고 있어요. 그래서 가로 x 세로 x 4바이트로 계산해요.
  파일을 아무리 압축해도 픽셀이 크면 이 값은 안 줄어요.
- 초록 = 여유 / 노랑(120MB 초과) = 방송 전 확인 권장 / 빨강(250MB 초과) = 줄이는 걸 권장
- 보관만 하고 어디에도 안 쓴 그림은 세지 않아요 (화면에 안 올라가니까요).

■ 그림 자동 축소 상한 512 -> 1024 픽셀
- 칸 통이미지가 2배 규격으로 최대 778픽셀까지 오기 때문에 올렸어요.
- 상한 자체는 그대로 있어서 최악의 경우도 묶여 있어요 (26칸 전부 1024여도 약 86MB).

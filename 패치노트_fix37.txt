2. 게임 모드 (설정 → 스트리밍 설정)
- 🎤 단일 방송 / 🎊 합방 카드 2택 — 두 모드는 동시에 쓸 수 없어요 (곡천 확정).
- 단일: 기존 진행 인원 UI 그대로 (로컬 참여자 말 추가).
- 합방: "채널 추가 = 말 추가" 한 몸 — 연결 안 된 채널이 생길 수 없어요. 내 채널 포함 최대 6.
- 모드·구성을 바꾸고 [적용하고 새 회차 시작]을 누르면 ★반드시 새 회차 (진행 중이면 확인 팝업).

3. 합방 채널 연결 (멤버는 설치 0 — 로그인 동의 1번)
- [＋ 채널 추가]: 말 이름 적고 누르면 초대 링크가 복사돼요 → 멤버에게 전송.
- 같은 자리 합방: 이 컴 브라우저에서 멤버가 로그인하면 자동 연결 (완료 화면까지).
- 원격 합방: 멤버가 자기 컴에서 로그인 → "연결할 수 없음" 페이지가 떠도 정상! 그 페이지의
  주소창 주소를 통째로 복사해 받아서 [붙여넣기 → 연결]. 끝.
- 채널 행: 연결 상태(수신 중/연결됨/코드 대기) + 말 이름·이모지·색 꾸미기 + [해제].

4. 후원 규칙 (곡천 확정)
- 굴림 후원: 어느 채널이든 하나의 큐에 시간순 — 큐·전광판·최근 기록·로그에 [말이름] 채널 태그.
- 방어권(정확 일치 금액): 후원이 터진 채널의 방송인 말에게 자동 귀속 — 지목 카드 안 뜸.
  "다른 사람에게 쉴드는 그 채널 가서" 방송 안내로 운영. 단일 모드의 지목제는 그대로 유지.
- 수신 순간의 채널→말 매핑을 이벤트에 기록 → 되돌리기·재시작 복구·구성 변경 후에도 재현 불변.

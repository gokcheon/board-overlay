# 🎲 보드게임 오버레이 (Board Overlay)

> 치지직 스트리머 **김띵띵띵** 님의 방송 1주년을 축하하는 마음을 담아 만든 팬메이드 앱입니다. 🎂

후원이 주사위가 되는 방송용 보드게임 툴 — 시청자의 후원이 대기 큐에 쌓이고,
말이 보드판 위를 구르며 벌칙·미션이 진행됩니다. (OBS 오버레이 + 조작 대시보드)

**Donation-powered board game overlay for Chzzk streamers** — viewers roll the dice with donations.

## 주요 기능

- 치지직 후원 연동: 후원 금액 → 주사위 굴림, 정확 금액 후원 → 방어권(쉴드)
- 26칸 커스텀 보드: 칸 효과·스티커·말 꾸미기, 색 테마 5종, 커스텀 주사위 눈금
- 벌칙 타이머(전광판식)·미니게임(사다리·야바위)·공동 항아리 정산
- 합방 모드: 최대 6명의 방송인이 각자 채널로 후원을 받아 한 보드에서 플레이
- OBS 소스: 통합 1개 또는 파츠별(보드/전광판/타이머/상태바/알림/미니게임) 자유 배치

## ⚠ 이용 조건

- **무단 재배포 · 무단 수정 · 2차 배포 · 판매를 금지합니다**
- 공식 배포처는 이 저장소(github.com/gokcheon/board-overlay)뿐입니다
- 네이버/치지직 공식과 무관한 팬메이드이며, 사용에 따른 책임은 사용자에게 있습니다

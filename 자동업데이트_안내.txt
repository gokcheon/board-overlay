■ 처음 딱 한 번 준비 (약 10분)
① github.com 에서 계정 만들기 (무료, 이메일만 있으면 돼요)
② 로그인 → 오른쪽 위 [+] → [New repository]
   - Repository name: board-overlay  (원하는 이름 OK)
   - ★ Public 선택 (Private이면 지인 앱이 못 받아요)
   - [Create repository] 클릭
③ 이 폴더의 업데이트주소.txt 를 메모장으로 열어 맨 아래 빈 줄에
   "자기 아이디/저장소이름" 적고 저장  (예: gokcheon/board-overlay)
④ 올리기.bat 더블클릭
   - Git이 없다고 하면: 자동으로 열리는 다운로드 페이지에서 설치(다음다음) 후 다시 실행
   - "브라우저 로그인 창"이 뜨면: GitHub 로그인 → 허용 (딱 한 번이에요)
⑤ 끝! 5~10분 뒤 저장소의 Releases에 설치 exe가 자동으로 올라와요.
   진행 과정은 저장소 → Actions 탭에서 실시간으로 볼 수 있어요 (초록 체크 = 성공).

[보드게임 오버레이 1.0 fix35] 패치노트
=====================================

1. 한 줄 요약
- 안주 집계 표시 제거(쉬어가는 칸 확정) + 1인 모드 쉴드를 "🛡️ 쉴드 현재 N개"로 크게 표시.

2. 내용 (곡천 확정)
- 안주 칸 = 방송인이 안주 하나 먹고 지나가는 쉬어가는 칸(상호작용 없음) →
  시청자 상태바·조작앱의 "안주 N개" 집계 표시를 제거. (칸 자체·기록은 그대로 — 표시만 정리)
- 쉴드(방어권) 시청자 가독성 피드백 반영: 1인 방송에서는 상태바에
  "🍺 현재 N잔 적립중  🛡️ 쉴드 현재 N개" — 잔 적립과 같은 결로 큼직하게.
- 2인 이상(다인)은 기존 말별 🛡️ 표시 유지 — 다인용 개선안은 시청자 재피드백 후 결정 예정.

3. 변경 파일
- overlay.js / control(index.html·control.js) / server/version.py(35). 캐시 ?v=35. 엔진 무변경.

4. 검증
- 실렌더: 1인(쉴드 줄 표시·안주 숨김·컬러 이모지 강제) / 다인(쉴드 줄 없음·말별 🛡️ 유지) /
  조작앱 안주 칩 제거 — pageerror 0. node --check / py_compile / id 교차 / 인코딩 바이트 검사 통과.
